## 保留名称的业务断言与新增覆盖

- `graph_call_session_tests` 的六项业务测试保留。预算等待显式 Human resume；当前 Plugin 资源观察、immutable admission bindings、子图身份/输入/产物 provenance 保留。缺 wait executor、父 frontier 身份与延迟 wait 的额外回归仍在同模块。
- `run_access/tests.rs` 保留 pilot 读取工具、whole-response bytes、字段次序与 retained progress；状态 fixture 改为真实 create/accepted submission，`with_active` 只测试读取投影。
- `recovery_submission_lookup_matches_the_entire_key_and_attempt` 保留全部 key 字段、attempt 与幂等重提不写端口的断言。恢复决定取自 Kernel history，未知工具效果不由 Session 制造成功结果。
- `channel_settlement_preserves_assistant_completion_distinction` 直接对 Phase 验证 Turn 规则。`kernel_predecessor_closure_uses_authoritative_phase_and_session_turn_holds`、`kernel_successor_retention_refreshes_authoritative_settlement` 在真实控制前保留旧视图，再确认权威重读；`successor_retention_keeps_missing_and_first_invocation_evidence_distinct` 使用真实首轮结果。
- `executable_binding_requires_work_binding_but_does_not_scan_idle_history`、`latest_binding_does_not_search_older_results_or_input_commits`、`corrupt_input_binding_stops_the_ordered_commit_scan` 与 `graph_read_leases_share_identity_and_exclude_writers` 保留授权/绑定优先级和租约断言。
- `retained_graph_calls_protect_the_incoming_reference` 通过真实提交覆盖 Bound、Completed、Detached、Failed、Uncertain。旧 Prepared 只是旧 Runner 的瞬态，Kernel 不持久化该状态，因此移除该不可达 fixture；全部可达持久状态仍保护父/子引用。`kernel_single_delete_preserves_call_owner_and_child_references` 同样改为真实 Call Bound，删除失败后完整父/子 record 不变。
- `kernel_delete_rechecks_active_worker_even_with_a_settled_resource` 与 `kernel_graph_conversation_delete_rechecks_wait_child_phase_and_worker` 使用尚未 poll 的真实 drive 同步占位，drop 后释放；不向 active map 插入伪造 worker。
- `startup_finishes_recorded_abandon_intent_idempotently` 保留启动 intent 完成与重入。真实 active worker 的 abandon 结算后，经唯一注册表完成通知等待 worker 排空；不另存 queued 状态。
- `pending_control_and_session_coordination_are_observed_once` 用真实 gated worker 建立 pause/stop，Session 只收窄动作。`frozen_canvas_projects_expanded_modules_and_hides_execution_input` 保留 canvas 脱敏。

- [Runtime 测试去向](runtime-test-mapping.md) 另列 73 项 Runtime 主测试。`host_operations` 原 16 项及既有 7 项 Kernel 测试均保留；改由 Harness 连接 KernelScheduler，真实 Store commit 故障替代旧 save hook。未完成 invocation 不提前计 passes，Suspended/Cancelled 不提交生命周期，Interrupted 为 Human wait；已知非法 route/失败按既有 Code Settle。

## 实际验证与界限

构建目录固定为 `/tmp/anchor-goose-regression-target-core`。本表只记录实际已取得的结果；Host 最新全量、Goose 和最终合并结果由总验收入口补充。

- `cargo test -p anchor-graph-host`：61 unit + 4 lifecycle，全部通过、无 ignored；`cargo clippy -p anchor-graph-host --all-targets -- -D warnings` 通过。
- Runtime 由同一切片的 Runtime 负责人运行：155 unit + 7 integration + 2 doc，通过、无 ignored；其中 `graph::tests` 98 项包含两项 invocation authority。原始输出为本机 `/tmp/anchor-m3-runtime-full-final.log` 与 `/tmp/anchor-m3-runtime-migrated-final.log`，不将本表当作原始输出副本。
